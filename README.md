🚀 Login Page

Ini adalah Login Page dengan desain modern dan responsif, dibuat menggunakan HTML, CSS, dan (jika ada) JavaScript. 
Tampilan clean dengan efek glassmorphism dan background bertema alam untuk memberikan kesan fresh dan nyaman di mata.

✨ Fitur
- Form login dengan input Username dan Password.
- Remember me checkbox & Forgot Password link.
- Tombol Login yang menarik.
- Link ke halaman Register.
- Desain Glassmorphism dengan latar belakang bertema alam.
- Responsif di berbagai ukuran layar.

🛠️ Tech Stack
- HTML5
- CSS3

(Optional) JavaScript

📦 Cara Menggunakan
Clone repository ini:
git clone https://github.com/samuelgaluh/Login-Page.git

Buka file index.html di browser favoritmu.
